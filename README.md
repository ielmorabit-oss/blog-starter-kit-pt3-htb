# RA3 (PT-3) Seguretat web — Hack The Box

Documentació i evidències de resolució dels mòduls de **Hack The Box Academy** i la màquina **Meow** (Starting Point), elaborada per **Ilias El Morabit** per a l'assignatura **C037 - Seguretat i Alta Disponibilitat (ASIXC)** a l'**Institut Gabriela Mistral**.

## Índex de continguts

* [1. Intro to Academy](moduls/01-intro-to-academy.md) — Funcionament de HTB Academy, entorn Pwnbox i desplegament de targets.
* [2. Getting Started](moduls/02-getting-started.md) — Conceptes bàsics de pentesting, enumeració web i escalada de privilegis.
* [3. Introduction to Web Applications](moduls/03-introduction-to-web-applications.md) — Arquitectura web, protocol HTTP, HTML/CSS i vulnerabilitats freqüents (XSS, exposició de credencials).
* [4. Attacking Web Applications with Ffuf](moduls/04-attacking-web-applications-with-ffuf.md) — Fuzzing de directoris, extensions, subdominis, VHosts i paràmetres amb `ffuf`.
* [5. SQL Injection Fundamentals](moduls/05-sql-injection-fundamentals.md) — Consultes SQL, enumeració de bases de dades, bypass d'autenticació, atacs `UNION` i execució remota de codi (RCE).
* [6. Exercici extra: Màquina Meow](exercici-extra/meow.md) — Explotació pas a pas de la màquina *Meow* mitjançant connexió VPN i accés *Telnet* sense contrasenya.
